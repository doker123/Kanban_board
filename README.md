# Vue.js Task3 — Канбан-доска

## 📋 Описание проекта

Интерактивная канбан-доска для управления задачами, разработанная на Vue.js 3. Приложение позволяет создавать задачи, перемещать их между колонками с помощью drag-and-drop или кнопок, а также автоматически отслеживает просроченные задачи.

## ✨ Возможности

- **Создание задач** — добавление новых карточек с заголовком, описанием и дедлайном.
- **Редактирование** — inline-редактирование названия, описания и даты дедлайна прямо в карточке.
- **Drag-and-drop** — перетаскивание карточек между колонками мышью.
- **Перемещение кнопками** — кнопки ◀️ и ▶️ для пошагового перемещения карточки по колонкам.
- **Автоматическое отслеживание просроченных задач** — каждую минуту система проверяет дедлайны и переносит просроченные задачи в отдельную колонку «Просроченные задачи».
- **Архивирование** — возможность перенести задачу в архив.
- **Сохранение данных** — все изменения автоматически сохраняются в `localStorage` браузера.
- **Статистика** — отображение количества задач в каждой колонке.

## 🏗️ Структура колонок

| ID | Название колонки |
|----|------------------|
| 1  | Запланированные задачи |
| 2  | В работе |
| 3  | Тестирование |
| 4  | Выполненные задачи |
| 5  | Просроченные задачи |
| 6  | Архив |

## 🚀 Технологии

- **LocalStorage API**
- **CSS3** (Grid, Flexbox, CSS-переменные, градиенты, тени, анимации)
